# Lung Cancer Detection with Hybrid CNN-SNN

A hybrid CNN + Spiking Neural Network for 3-class lung cancer classification (normal, benign, malignant) from CT images.

## Dataset
IQ-OTH/NCCD (Kaggle)

## Architecture
- CNN feature extractor (3 conv blocks)
- SNN head with LIF neurons (direct encoding)
